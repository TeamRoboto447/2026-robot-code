# Auto/paths and tunable data (not hand-edited as code)

- `src/main/deploy/pathplanner/{autos,paths}/` — PathPlanner GUI-authored autonomous routines; edit via the PathPlanner app, not by hand. `NamedCommands` referenced by these paths are registered in `ShipOfTheseus.initializeNamedCommands()`.
- `src/main/deploy/turret_data.json` — empirical shot lookup table consumed by `TurretSubsystem`. Distances are inches; hood `angle` is true degrees from vertical (301 hood-motor rotations = 360°). Values recorded before the hood gear-ratio fix assumed 1 rotation = 1° and were converted with `23 + (old - 23) * 360/301`. `pythonUtils/turret_data.json` is an older dataset still in those old units: convert before copying it. Regenerate/edit via `pythonUtils/turret_lookup_generator.py` (see `pythonUtils/README.md`), then `cp` into `src/main/deploy/` and redeploy. `lookup_table_handler.py`/`lookup_table.json` are legacy visualization-only tools — the RIO ignores them.
